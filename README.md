# Customer Segmentation Using RFM Analysis & K-Means Clustering

## Overview
This project analyzes retail transaction data to segment customers based on their purchasing behavior.

## Key Analysis
- Data cleaning and preprocessing
- Recency, Frequency, and Monetary (RFM) analysis
- Exploratory Data Analysis (EDA)
- Feature scaling
- K-Means clustering
- Elbow Method and Silhouette Score
- Customer segment interpretation

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Customer Segments
The analysis identifies four customer segments based on purchasing behavior and provides targeted strategies for different customer groups.
